# Digital Design

This repository contains a series of examples and labs for learning the fundamentals of digital design. The material aims to support the learning process. Most of the material has been prepared by Prof. Juan David Guerrero Balaguera. It might contain material from other sources cited and referenced accordingly.

The resources in this repository have been created in July 2026 using the current state of the Open Source tools availabe at the moment. There is no waranty of future updates at the same pace that the open source tools evolve.
