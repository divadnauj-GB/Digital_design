# Multiplexers

This directory introduces several examples for describing multiplexors using verilog. 

## mux2to1-v1
This is a basic 2to1 multiplexer described using its logic function. 

## mux2to1-v2
A 2 to 1 multiplexer described in verilog using the ternary operator ? :

## mux4to1-v1

A 4 to 1 multiplexer described un verilog using its boolean expression .

## mux4to1-v2

A 4 to multiplexer described in verilog by instantiating three 2 to 1 multiplexers.
